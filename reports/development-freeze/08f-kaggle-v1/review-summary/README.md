# Identity evidence review

These two tables and charts were derived from the unchanged 08F V1 outputs after download. The original Kaggle figures remain in the safe evidence folder. The accuracy chart uses a full percentage axis and the original base-asset-clustered intervals.

Identity link accuracy is not odd-one-out accuracy. The support table counts how many input views contain the selected identity. An agreement of 1.0 may come from one view only; it is not confidence that all input views agree. Review states are provisional and have not been calibrated on the protected role.
