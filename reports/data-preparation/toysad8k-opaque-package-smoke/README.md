# ToysAD-8K opaque package smoke evidence

This report records the Notebook 03 checks for the 20-scene, 400-image opaque
model-input package.

The repository keeps only aggregate evidence. Raw images, private identifiers,
labels, boxes, masks, the private contact sheet, and the executed notebook stay
outside GitHub.

The current evidence is under `kaggle-v5-candidate/`. The word `candidate` is
intentional because the run used a verified pre-commit source snapshot with
`git_dirty: true`. The package checks passed, but this run must not be described
as a strict clean-snapshot release.
